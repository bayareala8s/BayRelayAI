# How to update [bayareala8s.com](https://www.bayareala8s.com/)

BayRelay marketing copy lives in [BAYRELAY_MINI_PRODUCT_PAGE.md](BAYRELAY_MINI_PRODUCT_PAGE.md).  
Contract template: [SOW_PRODUCTION_LAUNCH_42K.md](../SOW_PRODUCTION_LAUNCH_42K.md).

You edit the live site in **Wix** (not in this git repo). Steps below match the current site structure from [bayareala8s.com](https://www.bayareala8s.com/).

---

## 1. Add BayRelay under Mini Products

1. Log in to Wix → **Pages** → **Ready-to-Deploy Mini Products**.
2. **Add page** → name **BayRelay** → slug `/bayrelay`.
3. Paste sections from [BAYRELAY_MINI_PRODUCT_PAGE.md](BAYRELAY_MINI_PRODUCT_PAGE.md):
   - Hero
   - What you get (table or icon grid)
   - Architecture (upload `docs/bayrelay-architecture.png`)
   - Engagement & pricing
   - FAQ
   - CTA → `mailto:himanshu.bhadra@bayareala8s.com?subject=BayRelay%20Production%20Launch`
4. **SEO**: title + meta description from that file.

---

## 2. Update navigation

**Menu:** Solutions & Services | Ready-to-Deploy Mini Products ▼

Under Mini Products, add **BayRelay** at the top (new flagship).

Optional:

- **Self-Service File Transfer** → add banner: *“Now part of BayRelay — [Learn more](/bayrelay)”*
- **AI File Assistant** → cross-link: *“Knowledge-base agent included in BayRelay”*

---

## 3. Homepage tweaks

On **Home**, optional strip under “Cutting-Edge Technology Solutions”:

> **New:** **BayRelay** — Agentic file transfer in your AWS account. [Explore →](/bayrelay)

Or add a 5th mini-product card in the same style as existing products.
